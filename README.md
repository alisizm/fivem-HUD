## 🇬🇧 English Description

### 📖 Overview
If you're looking for a modern, optimized, and fully customizable HUD system for your server, Alisizm HUD is exactly what you need. It combines a clean, minimal design with powerful features to deliver a premium experience for roleplay servers.

### ✨ Key Features
*   **🎨 HUD & UI Customization:** Fully customizable HUD system. Change colors via the config, display player info (ID, online count, server name), and toggle individual HUD elements on/off.
*   **🚗 Vehicle Speedometer:** Smooth, modern, and minimal speedometer. Supports both **KM/H & MPH**, automatically activates inside vehicles, and is fully compatible with standard fuel systems.
*   **🧠 Player Status System:** Includes dynamic bars for Health, Armor, and Stamina, along with Hunger and Thirst indicators. Features an **Advanced Stress System** where stress increases while shooting or driving at high speeds, complete with screen effects.
*   **💰 Money System:** Separate displays for Cash and Bank balances. The money HUD can be toggled and is fully customizable.
*   **🗺️ Minimap & Location:** Configurable minimap visibility (e.g., hiding outside of vehicles), clean interface, and clear street name display.

### ⚙️ Technical Details & Setup
*   **Framework Support:** Fully compatible with `QBCore`, `Old QBCore`, `ESX`, and `New ESX`.
*   **Performance:** Highly optimized structure for extremely low MS usage, ensuring stable and efficient gameplay.
*   **Config System:** Control all HUD elements, customize colors, and adjust system behaviors directly from a robust configuration file.
*   **Installation:** Simple drag & drop, configure your settings, and start the resource.
